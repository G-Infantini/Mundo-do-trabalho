# TechConnect

Projeto acadêmico de site institucional fictício desenvolvido com HTML5 e CSS3.

## Conteúdo

- Cabeçalho e navegação interna
- Banner de apresentação
- Sobre a empresa: missão, visão e valores
- Quatro serviços
- Três projetos ilustrativos fictícios
- Três diferenciais
- Três depoimentos fictícios
- Formulário de contato com validação nativa HTML
- Rodapé com contatos e links

## Como executar

Abra o arquivo `index.html` em um navegador. Não são necessárias dependências ou instalação.

## Observação

O formulário é demonstrativo e não envia mensagens a um servidor. Dados, clientes e projetos são fictícios.

## Tecnologias

HTML5, CSS3, CSS Grid, Flexbox, media queries e SVG.
